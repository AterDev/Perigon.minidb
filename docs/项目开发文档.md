## 4. 开发规范

### 4.1 代码风格
- 遵循 .NET 命名约定
- 使用 file-scoped namespaces
- 使用 primary constructors（当适用）
- 使用 collection expressions `[.. collection]`
- 使用 switch expressions（当适用）
- 最小权限原则：`private` > `internal` > `protected` > `public`

### 4.2 性能要求
- 避免不必要的内存分配
- 使用 Span<T> 处理临时缓冲区
- 使用 ArrayPool 复用大缓冲区
- 使用 FrozenDictionary 缓存元数据
- 异步方法使用 ConfigureAwait(false)

### 4.3 线程安全
- 所有共享状态使用 Lock 或 SemaphoreSlim
- 异步方法使用 SemaphoreSlim
- 文件读取支持并行，写入在 SaveChanges 路径中直接执行
- 避免 lock 语句嵌套

### 4.4 错误处理
- 使用 ArgumentNullException.ThrowIfNull()
- 具体的异常类型（避免泛用 Exception）
- 包含上下文信息的错误消息
- 不吞咽异常（除非有充分理由）

## 5. 使用指南

### 5.1 定义实体
```csharp
using System.ComponentModel.DataAnnotations;

public class User
{
    public int Id { get; set; }
    
    [MaxLength(50)]
    public string Name { get; set; } = string.Empty;
    
    [MaxLength(100)]
    public string Email { get; set; } = string.Empty;
    
    public int Age { get; set; }
    public decimal Balance { get; set; }
    public DateTime CreatedAt { get; set; }
    public bool IsActive { get; set; }
    public int? CategoryId { get; set; }
    public DateTime? PublishedAt { get; set; }
}
```

### 5.2 定义 DbContext
```csharp
using Perigon.MiniDb;

public class MyDbContext : MiniDbContext
{
    public DbSet<User> Users { get; set; } = null!;
    public DbSet<Product> Products { get; set; } = null!;
}
```

### 5.3 基本操作
```csharp
// 创建/打开数据库
await using var db = new MyDbContext("app.mds");

// 添加
db.Users.Add(new User 
{ 
    Name = "Alice", 
    Email = "alice@example.com",
    Age = 30,
    Balance = 1000m,
    CreatedAt = DateTime.UtcNow,
    IsActive = true
});
await db.SaveChangesAsync();

// 查询
var activeUsers = db.Users
    .Where(u => u.IsActive && u.Balance >= 500)
    .OrderByDescending(u => u.CreatedAt)
    .ToList();

// 更新
var user = db.Users.First();
user.Balance += 100;
db.Users.Update(user);
await db.SaveChangesAsync();

// 删除
db.Users.Remove(user);
await db.SaveChangesAsync();
```

### 5.4 内存管理
```csharp
// 多个上下文内存隔离
await using var db1 = new MyDbContext("app.mds");
await using var db2 = new MyDbContext("app.mds");
// db1 和 db2 通过文件持久化协同；查询/保存会进行版本检测
```

## 6. 性能指标

### 6.1 内存占用
- 文件大小 = 内存占用（全内存加载）
- 元数据缓存：< 1KB/表
- 变更追踪：O(n) 已修改实体数量
- 上下文隔离缓存，生命周期清晰

### 6.2 操作性能
- **查询**：内存速度（微秒级）
- **插入**：O(1) 追加 + 直接写入
- **更新**：O(1) 定位 + 直接写入
- **删除**：O(1) 标记 + 直接写入
- **SaveChanges**：取决于变更数量和磁盘性能

### 6.3 并发性能
- 读取：支持并行（上下文内同步保护）
- 写入：同一文件在同一进程内串行化提交
- 吞吐量：取决于磁盘速度

### 11.3 技术架构

#### MVVM 模式
```
Views (XAML)
   ↓ 数据绑定
ViewModels (逻辑层)
   ↓ 调用服务
Services (业务层)
   ↓ 使用模型
Models (数据层)
```

#### 项目组件
- **Models**: 数据模型（DatabaseConnection, TableInfo）
- **ViewModels**: 视图模型（MainViewModel）
- **Views**: 视图和对话框（MainWindow, ConnectionDialog）
- **Services**: 业务服务（DatabaseConnectionService, DatabaseReaderService）
- **Helpers**: 辅助类（RelayCommand）
- **Sample**: 示例数据库上下文（SampleDbContext）

### 11.4 使用说明

详细使用说明请参考：`src/Perigon.MiniDb.Client/README.md`

#### 快速开始
1. 运行应用程序
2. 首次启动会自动在 Documents 目录创建示例数据库
3. 点击 "Add Connection" 添加数据库连接
4. 选择连接后点击 "Connect"
5. 在左侧选择表，右侧查看和编辑数据
6. 修改后点击 "Save Changes" 保存
