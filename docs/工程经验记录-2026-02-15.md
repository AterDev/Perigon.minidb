# Perigon.MiniDb.Client 工程经验记录（2026-02-15）

## 1) MAUI 菜单显示在新的一行（非标题栏）

### 现象
- `ContentPage.MenuBarItems` 在 Windows 下显示为单独菜单行，不在与最小化/最大化/关闭同一行。

### 结论
- 这是 `ContentPage.MenuBarItems` 在当前 MAUI/WinUI 组合下的常见行为。
- 若要进入标题栏区域，需使用 `Window.TitleBar` 做自定义（Windows 特化实现）。

### 当前落地方案
- 在 `App.xaml.cs` 为 Windows 构建自定义 `TitleBar`。
- 将核心操作（连接、断开、刷新、重置、主题）放到标题栏按钮。
- Windows 下清空 `MainPage` 的 `MenuBarItems`，避免出现双菜单行。

## 2) 管理连接弹窗“关闭/浏览文件”点击不生效

### 现象
- 弹窗中“关闭”和“浏览文件”点击无响应。

### 根因与排查要点
- Blazor 事件传播在弹层中容易受冒泡影响。
- MAUI 平台能力（如 `FilePicker`）在 Hybrid 场景应确保 UI 主线程调用。

### 修复
1. 事件传播修复（`AppHost.razor`）
	 - 弹窗容器增加：`@onclick:stopPropagation="true"`。
	 - 关键按钮（关闭、浏览）添加显式 `@onclick` 与 `@onclick:stopPropagation="true"`。
2. 文件选择器主线程修复（`DesktopFilePickerService.cs`）
	 - 使用 `MainThread.InvokeOnMainThreadAsync(() => FilePicker.Default.PickAsync(...))`。

### 官方依据
- `MainThread.InvokeOnMainThreadAsync`：用于在 UI 主线程执行平台 UI 相关调用。
	- https://learn.microsoft.com/dotnet/maui/platform-integration/appmodel/main-thread?view=net-maui-10.0
- Blazor 事件传播说明：`@on{event}:stopPropagation`。
	- https://learn.microsoft.com/aspnet/core/blazor/components/event-handling?view=aspnetcore-10.0#stop-event-propagation

## 3) 主题一致性与弹窗视觉

### 现象
- 弹窗样式与主题不一致（深浅色不跟随）。

### 修复
- 弹窗结构放入主题容器（`.page-root`）内部。
- CSS 增加弹窗变量：遮罩、阴影、按钮主/危险/幽灵态，统一深浅色。

## 7) 第三轮改进（同日追加）—— 全量中英文支持

### 目标
- 用户要求“所有内容都支持中英文”，特别是 Windows 标题栏下拉菜单。

### 实施
1. 标题栏菜单文本本地化来源统一到 `MainViewModel`：
	- 顶级项：连接 / 视图 / 外观
	- 子项：管理连接、连接数据库、断开、刷新、重置视图、主题、语言
2. 语言切换后标题栏实时刷新：
	- `App` 注入 `MainViewModel`
	- 监听 `PropertyChanged(LanguagePreference + 相关菜单字段)`
	- 在主线程重建并替换 `Window.TitleBar`

### 同步稳定性补丁
- 弹窗按钮增加 `@onclick:preventDefault="true"`
- 强化 `overlay/dialog/dialog-btn` 的 `pointer-events: auto`

## 8) 第四轮改进（同日追加）—— 稳妥边界方案

### 目标
- 菜单与事件全部原生（MAUI/WinUI）
- Blazor 只负责内容展示与数据交互

### 方案
1. `AppHost` 移除“管理连接”Blazor弹层与相关事件处理。
2. `MainPage` 成为菜单动作原生协调层（包括标题栏菜单和页面菜单）。
3. 新增原生 `ConnectionManagerPage`（MAUI 页面）承载连接管理 UI：
	- 关闭按钮：原生导航 `PopModalAsync`
	- 浏览文件：原生按钮 + `FilePicker` 服务
	- 增删改连：直接绑定 `MainViewModel` 命令

### 收益
- 明确边界，避免 Blazor/WebView 指针事件链路影响关键系统操作。
- 菜单行为与弹窗行为统一使用原生机制，更稳定可预测。
